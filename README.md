I'm an economist, data scientist and AI engineer, currently a Senior Applied Scientist at
**Caseware**. Before that I spent four years at **Kiwi Financial**, a fintech that helps
underbanked Latinos in the U.S. build credit and access capital, where I grew from lead data
scientist to Head of Data Science. I like the part of AI work where a promising model has to
become a dependable system, and where a team has to learn to build that way together.

## What I do

- **Production AI agents.** I build multi-agent systems that do real work, not just answer FAQs.
  They take account actions, guide technical troubleshooting, route by context and escalate
  across text and voice. Stack: LangChain, LangGraph, LangSmith, OpenAI and Gemini.
- **MCP architecture.** I designed a custom async Model Context Protocol layer for LLM agents,
  with joined traces, parallel node execution, async processes and deterministic context injection.
- **LLM-driven operational intelligence.** I use rubric-based LLM evaluation for QA, compliance
  monitoring, CSAT analysis and negative-feedback triage.
- **Data platforms.** I led the move from querying production databases directly to a Snowflake
  warehouse with a medallion architecture, PII controls and role-based access, with Metabase for
  BI and Airflow for ML pipelines.
- **Machine learning.** I've built credit-risk and fraud models on AWS SageMaker, survival analysis
  and CNN-RNN remaining-useful-life models for industrial sensors, and forecasting for markets.
- **Team leadership and standards.** I lead data scientists who also own backend services. I set
  standards for documentation, modular DRY code, testing, API services and PR review, and
  introduced AI-assisted development with Claude Code and Antigravity, covering skill
  lifecycles, structured agent workspaces and review practices.
