I'm an economist, data scientist and AI engineer. I build machine learning systems for financial
markets, bringing an economist's view of how markets work, a data scientist's rigor with
evidence, and an engineer's habit of shipping things that run. I care about the
part of quant research that usually gets skipped: the evidence. That means point-in-time data,
leakage-safe validation, and a model that has to earn its way past a sealed out-of-sample gate
before it touches real capital.

## What I'm building now

Most of my current work lives in [**adg-finance**](https://github.com/adg-finance), where we're
building a research-to-production stack for a trader that learns from its own mistakes.

- **Portfolio engine.** An ML4T-style research pipeline that runs from Alpaca market data through
  features, triple-barrier labels and purged cross-validation to position sizing, with a
  deflated-Sharpe promotion gate in front of live trading.
- **Finance & AI wiki.** A knowledge base, maintained by LLM agents, that distills books and papers
  on markets and machine learning into linked concept pages. It's the reference shelf the
  pipeline is designed against.
- **Agent skills.** Reusable skills that make coding agents follow one discipline for specs,
  plans, reviews and research across Claude Code, Codex and Antigravity.
- **to-markdown.** A converter that turns EPUB and PDF books into clean Markdown that LLMs and
  agents can ingest.
